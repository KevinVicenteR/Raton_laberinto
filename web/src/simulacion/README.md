# simulacion

Consulta el catálogo publicado y reproduce sesiones de simulación o registros.

Entradas: catálogo y archivos de sesión existentes.
Salidas: pantalla de simulación, reproducción y muestras para los mapas.
Parámetros: selección de sesión, velocidad y posición de reproducción.
Reúne componentes, hooks, estado de reproducción y validación de sesiones.
Pruebas: `cd web && npm test` (catálogo y sesiones en __tests__).
No genera los archivos de web/public/sim; los consume.
